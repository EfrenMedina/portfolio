# Portfolio

Personal portfolio built with **Next.js**, **React**, **Tailwind CSS**, and TypeScript.
Light/dark theme, fully responsive.

## Development

```bash
npm install
npm run dev      # http://localhost:3000
```

## Editing content

All site content lives in [`lib/data.ts`](lib/data.ts) — edit that one file to update
your bio, skills, education, experience, and projects.

## Build

```bash
npm run build    # production build
npm start        # serve the production build
```
